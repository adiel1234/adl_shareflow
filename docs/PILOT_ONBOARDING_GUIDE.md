## קובץ לשיתוף

## להפצה למנהל

### עדכון קישורים לפני שליחה

| קישור | הערה |
|--------|------|
| **TestFlight** | שלחו את קישור ההזמנה בוואטסאפ / מייל — המדריך מציין «הקישור יישלח אליכם בוואטסאפ» |
| **APK Android** | דף ההורדה: `https://adlshareflow-production.up.railway.app/download` |
| **WhatsApp** | שלחו קישור הזמנה לקבוצה בהודעה אישית (ראו למטה) |

### איך להזמין משתתפים לקבוצת WhatsApp

1. פתחו את **WhatsApp** → הקבוצה שיצרתם
2. לחצו על **שם הקבוצה** למעלה → **הוספת משתתפים** (או «Invite via link»)
3. בחרו **«הזמנה באמצעות קישור»** / **Invite via link**
4. לחצו **«העתק קישור»** / **Copy link**
5. שלחו את הקישור בהודעת האונבורדינג (וואטסאפ או מייל) לכל משתתף
6. המשתתף לוחץ על הקישור → **פתיחה ב-WhatsApp** → **הצטרפות לקבוצה**

> טיפ: אפשר לשלב את קישור TestFlight, קישור קבוצת WhatsApp וקישור למדריך HTML באותה הודעת פתיחה.
