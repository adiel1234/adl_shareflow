## פרסום ידני ב־iOS — איך לוודא

ב־App Store Connect בעת שליחה לביקורת:

- **Version Release** → בחרי **Manually release this version**  
  (לא Automatic release after approval)

אחרי אישור Review הסטטוס יהיה משהו כמו «Pending Developer Release» — ואז ביום 20 לוחצים Release.
