שיתוף הוצאות קל ומהיר — גרסת בטא לקבוצת הפיילוט

🍎 iPhone 🤖 Android 1.0.5 · build 22

ברוך הבא לפיילוט!

נבחרתם לקבוצת הבטא של ShareFlow מבית ADL Projects. תודה שאתם עוזרים לנו לבנות את האפליקציה הטובה ביותר לשיתוף הוצאות.

בחרו את המכשיר שלכם והתקינו את האפליקציה:

✈️ הצטרפות ל-TestFlight
📥 הורדת APK ל-Android
🌐 דף הורדה חלופי (שני המכשירים)
⚙️ הערה למנהל הפיילוט
עדכנו את קישור TestFlight ב-href או הגדירו TESTFLIGHT_URL ב-Railway. ל-Android: הגדירו APK_DOWNLOAD_URL — דף /download יפנה אוטומטית.
🎁

אין תשלום — הפיילוט חינמי לחלוטין

גם אם האפליקציה מציגה מחירים או מסך הפעלה — אין חיוב בגרסת הפיילוט. התשלומים כבויים בשרת (PAYMENTS_ENABLED=off) ולא יגבו מכם כסף אמיתי. השתמשו באפליקציה בחופשיות.

התקנה — iPhone (TestFlight)

1

התקינו TestFlight

אם אין לכם — הורידו בחינם מ-App Store. חפשו TestFlight (מפתח: Apple).

פתיחה ב-App Store

2

פתחו את קישור ההזמנה

לחצו «הצטרפות ל-TestFlight» למעלה — או על הקישור שקיבלתם ב-WhatsApp / במייל.

3

קבלו והתקינו

ב-TestFlight לחצו Accept / קבל, ואז Install / התקן ליד ADL ShareFlow.

4

התחברות והצטרפות

פתחו את ShareFlow, הירשמו או התחברו, והצטרפו לקבוצה דרך קישור ההזמנה שקיבלתם.

התקנה — Android (APK)

1

אפשרו התקנה ממקורות לא ידועים

הגדרות → אבטחה / אפליקציות → אפשרו «התקנה ממקורות לא ידועים» לדפדפן או ל-Files (שם תורידו את הקובץ).

2

הורידו את ה-APK

לחצו «הורדת APK» למעלה, או פתחו:

adlshareflow-production.up.railway.app/download

הדף יזהה Android ויפנה ישירות לקובץ ה-APK.

3

התקינו את הקובץ

פתחו את קובץ ה-.apk מההורדות → לחצו התקן. אם מופיעה אזהרת אבטחה — אשרו (זו גרסת פיילוט חתומה על ידנו).

4

פתחו והתחברו

לאחר ההתקנה — פתחו ShareFlow, הירשמו והצטרפו לקבוצה דרך קישור ההזמנה.

💡 ב-iPhone — שמרו את TestFlight במסך הבית לעדכונים. ב-Android — כשתשוחרר גרסה חדשה, הורידו APK מחדש מאותו דף.

💬 קבוצת WhatsApp של הפיילוט

שתפו איתנו רושם, רעיונות, באגים ומשוב — הקבוצה היא המקום המרכזי לתקשורת עם צוות ADL.

📱 הצטרפות לקבוצת WhatsApp

🔧 שאלות נפוצות

האם אשלם משהו?

לא. הפיילוט חינמי. מסכי מחיר או הפעלה באפליקציה אינם גובים תשלום אמיתי.

iPhone: «Processing» / Build לא זמין

Apple מעבדת build חדש (5–30 דקות, לפעמים עד שעה). חזרו לקישור מאוחר יותר.

Android: «חסום להתקנה»

ודאו שאפשרתם התקנה ממקורות לא ידועים. נסו להוריד שוב מדף /download.

גרסה ישנה מותקנת

iPhone: TestFlight → Update. Android: הורידו APK חדש. גרסה נוכחית: 1.0.5 build 22.

לא מגיעות התראות

הגדרות המכשיר → ShareFlow → התראות → אפשרו. ב-iPhone גם ב-TestFlight.

איך מדווחים על באג?

בקבוצת WhatsApp או במייל לתמיכה — תארו מה עשיתם, מה ציפיתם ומה קרה. צילום מסך עוזר מאוד.

צריכים עזרה?

שאלות, תקלות או משוב — נשמח לשמוע.
