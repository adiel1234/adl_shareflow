Open
3

קבלו את ההזמנה

ב-TestFlight יופיע ADL ShareFlow. לחצו Accept / קבל כדי לאשר השתתפות בבדיקות.

התקינו את ShareFlow

לחצו Install / התקן. ההתקנה דומה להתקנת אפליקציה רגילה — אין צורך «לסמוך על מפתח» כמו בגרסאות Enterprise.

Install
5

פתחו והתחברו

לאחר ההתקנה — פתחו את ShareFlow, הירשמו או התחברו, והצטרפו לקבוצה דרך קישור ההזמנה שקיבלתם.

עדכונים והתראות

כשתשוחרר גרסה חדשה — TestFlight ישלח התראה. פתחו TestFlight → ShareFlow → Update. מומלץ לאפשר התראות Push גם ל-ShareFlow.

Update

🔧 פתרון בעיות

«Processing» / «מעבד» — Build לא זמין

Apple מעבדת build חדש (לרוב 5–30 דקות, לפעמים עד שעה). חזרו לקישור מאוחר יותר. אם מופיע «Unable to Install» — ה-build עדיין לא מוכן.

גרסה ישנה מותקנת

פתחו TestFlight → ADL ShareFlow → בדקו אם יש כפתור Update. אם לא — משכו למטה לרענון. גרסת הפיילוט הנוכחית: 1.0.9 build 62.

לא מגיעות התראות

הגדרות → ShareFlow → התראות → אפשרו. גם ב-TestFlight: הגדרות → התראות. וודאו שמצב «לא להפריע» כבוי.

הקישור לא נפתח / «הזמנה לא תקפה»

ודאו שאתם ב-iPhone (לא Android). נסו להעתיק את הקישור ל-Safari. אם עדיין לא עובד — פנו לתמיכה (פרטים למטה).

Build פג תוקף (Expired)

Builds של TestFlight תקפים ~90 יום. אם האפליקציה הפסיקה לעבוד — צרו קשר; נשחרר build חדש.

אין מקום ב-iPhone

ShareFlow דורשת ~50 MB. פנו מקום והתקינו מחדש דרך TestFlight.
