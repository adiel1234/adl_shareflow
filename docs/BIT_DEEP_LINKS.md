# אינטגרציית Bit ב-ShareFlow

עודכן: 2025-06-05

## מה Bit תומך בו

| יכולת | זמין ל-ShareFlow? | הערות |
|--------|-------------------|--------|
| פתיחת אפליקציית Bit (`bit://`) | כן | הסכמה הרשומה ב-iOS/Android; נבדק ב-Safari |
| מילוי אוטומטי של סכום + טלפון מקבל ב-URL | **לא** | אין תיעוד רשמי; ניסיונות `bit://pay?amount=…&phone=…` נפתחים אך Bit מתעלם מהפרמטרים |
| תשלום P2P עם סכום מוכן מצד שלישי | **לא** | העברות בין אנשים נעשות מתוך האפליקציה בלבד |
| תשלום לעסק (bitcom) | רק לסוחרים | קישורי `public.bankhapoalim.co.il/bitcom/...` עם `transactionSerialId` שנוצר בשרת הסליקה — לא מתאים לחובות בין חברי קבוצה |

## מה ShareFlow עושה היום

1. מציג גיליון אישור עם **סכום בולט** ומספר טלפון המקבל.
2. כפתור **העתק סכום** — המשתמש מדביק ב-Bit אחרי הפתיחה.
3. כפתור **פתח Bit** — `bit://` בלבד (ללא path/פרמטרים, כדי לא לשבור את הפתיחה).

## מה אי אפשר לעשות (מגבלת מוצר Bit)

- לפתוח את מסך ההעברה ב-Bit עם הסכום והטלפון **כבר מלאים** — דורש API/שותפות בנקאית (למשל Hyp, Tranzila, Allpay) ולא deep link פשוט.
- לשלוח "בקשת תשלום" Bit בשם המקבל מתוך ShareFlow — בקשות נוצרות רק מתוך אפליקציית Bit.

## כיוון עתידי (Pro)

## בדיקה ידנית (Safari ב-iPhone)

```
bit://
bit://pay?amount=100&phone=0501234567
bit://send?amount=100&phone=0501234567
```

אם כולם פותחים את Bit **בלי** סכום/טלפון מוכנים — אין פורמט ציבורי ל-P2P.
