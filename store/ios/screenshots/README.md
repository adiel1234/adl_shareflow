# צילומי מסך ל־App Store (iPhone)

**גודל חובה (מחלקת 6.9"):** אחד מ־`1320×2868` / `1290×2796` / `1260×2736`.

הסקריפט מצלם על סימולטור `iPhone 17 Pro Max` (1320×2868):

```bash
./scripts/capture_store_screenshots.sh
```

קבצים צפויים:
- `01_home.png`
- `02_expenses.png`
- `03_balances.png`
- `04_invite.png`

להעלות ל־App Store Connect → גרסת האפליקציה → Screenshots → 6.9".
אל תבנה IPA סופי רק בשביל צילומים.
